| ⭐ [ContextForge](https://github.com/SuarezPM/Apohara_Context_Forge) | The first formally-verified safety layer for multi-agent LLM pipelines. Share the KV-cache to make agents affordable — without silently corrupting your judges. 44% fewer prompt tokens, 3.55× KV-cache VRAM reduction at INT4, 0/1210 safety violations. Carries a permanent [Zenodo DOI](https://doi.org/10.5281/zenodo.20277875). **Flagship.** | Apache-2.0 |
